# Requirements & Architectural Plan: Luxury Safety Net Websites

## Executive Summary
The goal of this project is to build **three distinct, highly tailored, ultra-fast, mobile-first websites** for three safety net clients (`a r safetynets`, `k r safetynets`, `v r safetynets`).
The core operational logic and page structure will inherit the comprehensive feature set of the reference implementation at `D:\all projects\virat\v4` (e.g. `trustynets`), but each site will sport a **unique, high-end, luxury fashion-inspired design identity**.

---

## 1. Core Requirements & Constraints

1. **Strict No-Action Directive**: 
   - No source code or content modification will occur until explicit confirmation and approval is given by the user.

2. **Structure & Pages (Based on `D:\all projects\virat\v4`)**:
   - Each client site will contain complete page routing and structure matching the reference blueprint:
     - `index.html` (Homepage with hero, services, highlights, call-to-actions, testimonials)
     - Service Detail Pages:
       - `balcony-safety-nets.html`
       - `child-safety-nets.html`
       - `cricket-safety-nets.html`
       - `pigeon-safety-nets.html`
       - `invisible-grills.html`
       - `rooftop-solutions.html`
     - Utility & Informational Pages:
       - `about.html`
       - `why-us.html`
       - `locations.html`
       - `faq.html`
       - `safety-advisor.html` (Interactive safety recommendation / calculator tool)

3. **Three Distinct Luxury Brands**:
   Each of the 3 client sites (`a r safetynets`, `k r safetynets`, `v r safetynets`) must feature a completely unique visual aesthetic inspired by haute couture, luxury fashion, and premium architectural design:
   - **Client 1: `a r safetynets`** → *Vogue / Minimalist Editorial Aesthetic* (Serif typography, generous whitespace, stark high-contrast monochrome with champagne/warm gold accents).
   - **Client 2: `k r safetynets`** → *Modern Glassmorphic Dark Luxury* (Deep obsidian, sleek neon subtle glows, frosted glass cards, dynamic micro-interactions).
   - **Client 3: `v r safetynets`** → *Architectural / High-End Estate Aesthetic* (Rich emerald/sapphire tones, bronze/copper accents, elegant geometric grid layouts).

4. **Performance & Mobile-First Focus**:
   - **Mobile-First UX**: Native app-like feel on mobile devices, optimized touch targets, sticky bottom action bar (Call/WhatsApp), smooth modal drawers.
   - **Ultra-Fast Performance**: Zero bloat, instant page transitions, optimized lightweight asset loading, inline critical styles.

5. **Inspiration Synthesis (Test Folder Analysis)**:
   - Deeply analyze inspiration prototypes (`aura.html`, `guardian.html`, `velour.html`, `test1.html`, `test2.html`, `test3.html`) under [test-inspiration](file:///d:/all%20projects/safetynets-3/test-inspiration).
   - Blend structural strengths (interactive calculators, instant lead capture forms, dynamic trust badges) with high-fashion aesthetic elements (smooth cursor interactions, editorial hero sections, sleek video/image presentation).
